# 剪发术语中英词典

标准术语 + 口语别名映射。口语别名是模糊需求的检索入口：**用户说的几乎不会是术语，必须能反查。**

用法：第 3 段术语映射时查此表；第 2 段参数化补全时用「口语别名」列定位歧义源。

## 使用纪律

**这张表只用于翻译用户已经说出口的需求，不用于替用户选方案。**

- 「适配脸型」「效果」列 → **解释**用户已选中的术语为什么这么呈现，**不用于**反过来从脸型推导用户该选什么
- 「男士发型命名」表 → 用户问「这叫什么」时**回答**；用户没问就不主动报发型名
- 用户从效果描述（「显脸小」）出发时，**先查效果列反查可能的部位改动，追问让他选**，不直接从脸型列推出方案

一句话：**这张表回答「这个术语是什么意思」，不回答「你应该剪哪个」。**

## 一、长度（单位换算）

术语体系里长度有三套单位并存，理发店实际沟通中「寸」最通用。

| 换算 | 数值 |
|---|---|
| 1 寸 | 约 3.3cm（行业惯用，非精确换算） |
| 1cm | 约 3 分（「分」是理发行业惯用单位，1 分 = 1/8 英寸 ≈ 3.2mm；**不是 3mm**） |
| 板寸 | 约 1cm 上下 |
| 圆寸 | 3-5mm，贴头皮 |
| 男士「寸头」泛称 | 长度 1 寸（约 3.3cm）以下 |

> ⚠️ 毫米（mm）在理发店是**卡尺／限位梳编号**，指推完后**留在头上的长度**，不是剪掉的量。说「留 5mm」，顾客常听成「剪掉 5mm」——实际是贴头皮推一遍。这类数字**只进指令卡，不进追问**，见下方「双参照系」表。

**关键锚点参照物**（比数字更重要，理发师和用户都能对齐）：

| 锚点 | 位置 |
|---|---|
| 耳上 | 耳朵上缘水平线 |
| 耳垂 | 耳朵下缘 |
| 下颌线 | 下巴最宽处 |
| 眉上 | 眉毛上方约 1cm |
| 齐眉 | 与眉毛齐平 |
| 锁骨 | 肩部前方的骨性标志 |
| 肩线 | 肩峰水平线（长发剪短最常见的第一步分界） |
| 胸线 | 胸部上方，长发中段常见底线 |
| 腰线 | 腰部最细处，长发保留的极端底线 |
| 后颈发际线 | 脖子与后脑交界 |

### 顾客的随身参照尺

位置锚点解决「剪到哪儿」，但有三种情况位置不够用：用户说不清具体位置、要表达的小于 5cm、或者长发需要一个比例。这时换下面两个参照系——**用户手上和身上现成的，不需要任何转换。**

**一、手部度量**（适合 1-20cm 的短距离）

| 参照 | 约等于 |
|---|---|
| 一根手指宽 | 1.5cm |
| 食指＋中指并拢 | 3cm |
| 三指并拢 | 5cm |
| 四指并拢 | 7cm |
| 手掌宽（不含手指） | 8-9cm |
| 手掌长（腕到中指尖） | 18cm |

**二、社会符号**（适合短发，用户一听就有画面）

| 顾客嘴里的说法 | 大致对应 |
|---|---|
| 军训头／刚入伍的那种 | 圆寸，3-5mm，贴头皮 |
| 三天没刮的胡茬 | 5mm 上下 |
| 板寸 | 约 1cm |
| 耳朵完全露出来 | 耳上，后脑约 3-6cm |

**三、现状对比**（长发最准，因为他低头就能看见）

「比现在短一半」「剪掉现在发长的三分之一」「从发尾往上收到锁骨」。用户有「现在」这个锚，对比现状永远比想象未来容易。

### 参照系怎么选（按场景）

| 场景 | 首选 | 例 |
|---|---|---|
| 两侧、后颈 | 结果（头皮可见度） | 几乎看到头皮／一层扎手的茬 |
| 短发（5cm 以下） | 社会符号 | 军训头／三天没刮的胡茬 |
| 中长发 | 手部度量＋位置 | 剪掉三指并拢，到耳垂 |
| 长发（过肩） | 现状对比＋位置 | 剪掉现在一半，到锁骨 |
| 刘海 | 结果＋位置 | 能不能盖住眉毛 |
| 用户全程说不清 | **让他用手捏** | 捏住一撮前发，手指停的位置就是不短于那儿 |

原则：**同一次追问里最多用两种参照**。三种全上会让用户又陷入选择疲劳——直观的目的是降低作答成本，不是展示参照物库存。

### 位置词口径表（不是精确词，是范围词）

用户说「剪到耳朵」，可能指三个位置。不拆开，后面全部对不上。

| 用户说的 | 可能指 | 追问怎么拆 |
|---|---|---|
| 剪到耳朵 | 耳上缘／耳朵中段／耳垂 | 是耳朵上边那条线，耳垂，还是耳朵中间 |
| 剪到下巴 | 下巴尖／下颌角／下巴下方两指 | 是下巴尖那条线，还是下颌骨转角 |
| 剪到下颌线 | 下巴尖／下颌骨转角／下颌骨下方一指 | 是下巴尖，还是耳朵下面那条骨头的转角（两者差 3-5cm，别混用） |
| 剪到肩膀 | 肩线／锁骨／肩缝 | 是肩膀最上面这条线，还是锁骨 |
| 齐眉 | 眉毛上缘／眉毛中间／刚好盖住 | 是眉毛上边，还是刚好盖住眉毛 |
| 到脖子 | 后颈发际线／脖子中段／喉结高度 | 后面发际线，还是脖子中间 |
| 到胸口 | 胸线上方／正好胸线／胸口以下 | 是刚到胸线，还是再往下 |

这张表**不依赖照片**，任何场景都要用。有照片时让用户在照片上指，更快。

### 照片视角能判断什么

| 视角 | 能读 | 读不出 |
|---|---|---|
| 正面 | 发长落点（下颌／锁骨）、刘海位置、两侧是否露耳、层次高低 | 后脑形状、层次起点 |
| 左侧／右侧 | 鬓角处理、耳周轮廓、侧面层次落差、后颈上半段 | 对称性（单侧看不出） |
| 后面 | **后颈颈线形状**、后脑轮廓、发尾齐不齐、是否一刀切 | 正面效果 |
| 多视角合看 | 两侧是否对称、整体轮廓 | 发质手感、头皮状态 |

**后面那张是四面里唯一不可替代的。** 其余三面照镜子就能看见，后脑是真正的 180° 盲区，也正好是争议最高发的地方（圆颈线 vs 留台阶）。

照片读不出发质手感——湿发照还会把长度拉长、层次抹平。**不要凭照片给发质方案**。

### 双参照系：同一个数字，两套说法

理发师用「剪除量 + 卡尺」，顾客用「看得见的结果」。两套体系不通，**数字加得再多也不会让顾客听懂**。

| 要表达的事实 | ❌ 顾客听不懂（理发师参照系） | ✅ 顾客参照系（追问只能用这一列） |
|---|---|---|
| 极短，贴头皮 | 「推 3mm」 | 几乎能看到头皮 |
| 很短，有一层茬 | 「推 5mm／圆寸」 | 留一层薄薄的短茬，摸上去扎手 |
| 短，能看出一层头发 | 「推 9mm／板寸」 | 能明显看出是一层头发，用手能抓起来 |
| 两侧处理方式 | 「推剪／Fade」 | 用推子从下往上推，还是只用剪刀修 |
| 层次 | 「高层次／低层次」 | 上面留长、下面收短（动起来有落差）／上下一样齐 |
| 打薄 | 「去量／打薄」 | 把厚度削掉一点，让头发轻一些、不那么鼓 |
| 后颈收边 | 「圆颈线／方颈线」 | 后颈边缘收成圆弧／留一条平的边 |
| 鬓角 | 「Taper／铲青」 | 耳朵前面的那一小撮头发怎么处理 |

**两条硬规则**：

1. **mm 数只进指令卡，不进追问。** 顾客没有毫米刻度，而且会把「留 5mm」误读成「剪掉 5mm」。
2. **问句里的数字必须是位置**（耳上／耳垂／后颈／锁骨／能扎起来／不盖眉毛），因为位置他能对着镜子验证。

## 二、层次结构

| 标准术语 | 英文 | 口语别名 | 效果 | 物理锚点 |
|---|---|---|---|---|
| 高层次 | High layers | 层次高、层次感强、要层次、蓬松、轻盈、有空气感 | 顶部轻盈蓬松，发尾轻 | 头顶留长，从中段开始变短 |
| 中层次 | — | 层次适中 | 上下过渡均衡 | 中段起自然过渡 |
| 低层次 | Low layers | 层次低、厚重、顺 | 保留发尾重量，轮廓整齐 | 仅发尾轻微去量 |
| 零层次 | — | 不打层次、不要层次、别打层次、无层次、一刀齐 | 厚重下垂、整齐 | 所有发片同长度 |

**连带术语**：

| 术语 | 英文 | 口语别名 | 说明 |
|---|---|---|---|
| 打薄 | Debulking | 打薄、削薄、薄一点、薄点、剪薄、牙剪、去量 | 用牙剪减量，降低厚重感 |
| 碎剪 | Texturizing | 碎发、剪碎、参差剪 | 剪出长短不一，增加动感 |
| 去量 | — | 减量、变薄一点 | 与打薄同义 |
| 高颅顶 | — | 头顶拉高、颅顶蓬松 | 顶部制造空气感，视觉增高 |

**层次选择与发质的强约束**（违反会翻车，必须提示）：

| 发质 | 适合层次 |禁忌 |
|---|---|---|
| 细软、发量少 | 高层次、增加发根支撑 | 低层次、厚重齐刘海（会贴头皮显精神差） |
| 粗硬、发量多 | 低层次或中层次 + 打薄 | 不打薄会炸开，无法成型 |
| 自然卷（沙发） | 顺卷保留长度 / 逆卷剪短防毛躁 | 按直发逻辑剪会翻车 |

## 三、刘海类型

| 标准术语 | 英文 | 口语别名 | 特征 | 适配脸型 |
|---|---|---|---|---|
| 空气刘海 | Air bangs | 空气刘海、透空气刘海 | 薄而透气，根部蓬松 | 圆脸、长脸 |
| 法式刘海 | French bangs | 法式刘海 | 介于齐与空气之间，随性 | 方脸、国字脸 |
| 空气齐刘海 | — | 空气齐刘海、齐刘海 | 齐但轻薄，透光 | 长脸（缩短脸部） |
| 八字刘海 | Curtain bangs | 八字刘海、眉骨分 | 中分后向两侧弯，修饰颧骨 | 圆脸、菱形脸 |
| 碎刘海 | — | 碎刘海、锯齿刘海 | 边缘参差，修饰额头 | 额头高、发际线不规整 |
| 韩式逗号刘海 | — | 逗号刘海、括号刘海 | 括号状，修饰宽额 | 额头宽 |
| 中分 | Center part | 中分 | 额前全露或近露 | 窄脸长脸 |
| 三七分 | Side part | 三七分、二八分、侧分 | 偏分，正式感 | 多数脸型 |
| 空气留白刘海 | — | — | — | — |

**强禁忌组合**（脸型 × 刘海，踩了就显脸差）：

- 圆脸 + 厚重齐刘海 → 脸被框得更短更圆
- 长脸 + 全部后梳（大背头、高马尾）→ 纵向拉长
- 方脸 + 一刀齐 BOBO（发尾卡在下颌）→ 给方下巴做取景框
- 额头高 M 字 + 全部向上梳 → 暴露短板

## 五、后颈收边（Neckline）

后颈是「用户看不见、师傅说了算」的区域，也是「圆满还是台阶」这个真实分歧的源头。
用户说「后脑勺修的圆满一点」「后面别留台阶」，指的就是这一节。

| 标准术语 | 英文 | 口语别名 | 特征 | 物理锚点 |
|---|---|---|---|---|
| 圆颈线 | Rounded neckline | 圆弧收边、后颈修圆、后脑勺修的圆满、圆着收、圆满一点 | 沿颈侧走自然弧线，无直角台阶 | 沿后颈发际线走一条连续弧线，中间不留平直段 |
| 方颈线 / 台阶 | Square neckline | 台阶、留个台阶、方块颈线、后面留一道、方的 | 左右两角方，中间平直，轮廓硬 | 两侧角位垂直收边，中间走一条水平线，形成方框 |
| 自然颈线 | Natural neckline | 顺着长、后面别动、自然收 | 按原有生长边界修整，不改变形状 | 只清杂发，保留原发际线走向 |

**必须量化的部分**：只说「修圆」「留台阶」都还不够，要补两项——
弧度起点（耳后 / 耳垂延长线）与收边高度（后颈发际线上方 0-2cm）。
不说高度，师傅可能一路推上去。这两项缺失时按第 2 段规则追问，不填默认值。

## 八、检索使用说明

第 2 段参数化补全时的操作顺序：

1. 用「口语别名」列匹配用户原话，定位到标准术语
2. 查该术语的「效果」列，确认用户想要的是不是这个
3. 取「物理锚点」列，作为第 3 段的兜底描述
4. 若该维度涉及剪除，**必须从「长度」节的锚点参照物中取一个具体位置**填入指令卡

**禁止行为**：只输出术语不输出锚点；只输出「剪短一点」这类无数字表述；用户没提的维度凭本表默认值填入卡片（刘海/发尾/层次无默认值）；用「效果」列反过来替用户挑方案。
